# PersonaBot UI/UX QA 验证清单

> 对应 UI/UX 打磨路线图 PR 1~PR 6（`fix/ui-errors-and-feedback` → `feat/ux-details`）的人工及自动化验收项。

## 1. 本地质量与构建门禁
- [ ] `npm run lint` — 无任何 ESLint error / warning（含 React 19 hooks 规则）
- [ ] `npm run typecheck` — `tsc --noEmit` 零报错
- [ ] `npm test` — Vitest 全部单元与集成测试通过
- [ ] `npm run build` — Next.js 16 生产构建成功
- [ ] `npx playwright` / Chrome Lighthouse Accessibility 检查得分 ≥ 95

## 2. 十项边界与体验细节核对

1. **极长消息与特殊字符**
   - [ ] 发送 2000+ 字连续无空格长文本及复杂 Markdown/代码块，聊天气泡与主舞台不产生水平滚动条。
2. **空白与超多数据状态**
   - [ ] 新创建 0 消息 Bot 时，展示 Click-to-Customize 吉祥物、简介与 **3 个定制开场建议卡片**（无 `master-bot` 与普通 Bot 错配）。
   - [ ] 右侧「记忆库」「成长日志」「版本快照」「纠偏记录」为空时，均展示说明“这里放什么 + 如何产生第一条数据”的空状态卡。
   - [ ] 拥有 20+ Bot、50+ 记忆或长列表时，`LeftSidebar` / `RightInspector` 滚动流畅不卡顿。
3. **加载态 Skeleton**
   - [ ] 切换 Bot 或首次打开对话历史时，展示用户/AI 骨架气泡占位，不闪烁空白或旧 Bot 记录。
   - [ ] 右侧栏加载、成长日志加载时展示 `Skeleton` 占位，而非孤立纯文本。
4. **失败态与内联重试**
   - [ ] 断网或后端返回 5xx 时，已发送的用户消息气泡下方出现内联「发送未成功 · 重试发送」按钮，并弹出带重试动作的错误提示条（Toast）。
   - [ ] 点击内联「重试发送」能复用同一条用户消息重新请求，且不重复插入气泡。
   - [ ] 浏览器 `online` 事件恢复网络后，之前失败的列表/详情请求自动重新同步。
5. **跨刷新草稿持久化**
   - [ ] 在 Bot A 与 Bot B 的输入框分别键入未发送草稿，刷新页面后各自草稿仍保留；清空或发送后自动清理存储体积。
6. **键盘导航与无障碍 (a11y)**
   - [ ] `⌘K` 打开命令面板，`⌘N` 打开新建 Bot，`⌘⇧I` 切右侧洞察面板，`⌘1~9` 切换前 9 个角色，`?` 打开快捷键速查弹窗，`Esc` 关闭任何已打开弹窗/抽屉。
   - [ ] 弹窗开启时 Tab / Shift+Tab 仅在弹窗内循环（Focus Trap），关闭后焦点回到原触发按钮。
   - [ ] 聊天消息容器标注 `role="log"` 与 `aria-live="polite"`；暗色模式下 `--text-muted` (`#9a9aa6`) 在 `#09090c` 与 `#111116` 上对比度 ≥ 4.5:1（WCAG AA）。
7. **动画与 Reduced Motion**
   - [ ] 切换桌面暗/亮主题、切换 Bot 主舞台、Tab 切换、气泡进场动画顺滑无抖动。
   - [ ] 系统开启“减弱动态效果 (`prefers-reduced-motion: reduce`)”后，关键位移动画与 FLIP 过渡自动降级为瞬时切换。
8. **响应式四断点**
   - [ ] `375×812`（手机）：汉堡菜单 + 底部半屏/全屏可拖拽抽屉 + 头部 `⋯` 更多菜单 + `100dvh` 输入栏贴底 + 触摸热区 ≥ 44px；移动端点击「分享」优先调用系统 `navigator.share`，不支持时降级剪贴板并 Toast 反馈。
   - [ ] `768×1024`（平板）：72px 图标轨侧边栏可展开 + 右侧栏滑入抽屉。
   - [ ] `1280×800` / `1920×1080`（桌面/宽屏）：三栏稳定，正文阅读列宽上限 `720px` 居中。
9. **导出/保存反馈**
   - [ ] 保存角色/人设/记忆修改提示「已保存修改」；导出灵魂包提示「已导出灵魂包」；分享片段提示「已复制对话片段」。
10. **二级页面与路由一致性**
    - [ ] `/persona/[slug]` 正确重定向至 `/chat/[slug]?inspector=1`；`/create`、`/gallery`、`/models`、`/login`、`/register`、`/admin` 共用同一套设计 Token 与头部导航。

# 人格评测基线 (Persona Eval Baseline)

评测完全基于纯 TS 规则（不调用模型），可在 CI 与离线环境稳定复现：

```bash
npm run eval:persona
```

## 指标说明
- **像本人分 (likeness)**：回复的气泡长度、emoji 频率、句尾句号、感叹号频率、口头禅命中，与角色「本人风格指纹」的接近程度。
- **去 AI 味分 (deAI)**：从 100 分扣除 AI 套话（每条 -15）、出戏泄露（每条 -40）、主持人式反问（-10）、舞台括号动作、Markdown 结构。
- **综合分 (total)** = 0.5 × likeness + 0.5 × deAI。

本人指纹来源：有原始聊天记录时用蒸馏指纹；否则取人设 Layer 2 中引号内的示例原话；都没有时用默认年轻人微信口吻。

## 2026-11-24 基线（离线兜底回复 × 16 个场景）

| 角色 | 平均综合分 | 最低去 AI 味分 |
|------|-----------|---------------|
| master-bot | 85 | 100 |
| grok-ella | 82 | 100 |
| lin-wan | 83 | 100 |
| su-nian | 81 | 100 |
| zero-arch | 85 | 100 |

> 离线兜底回复是模板生成的，所以去 AI 味分天然较高；真实模型回复会在每条 assistant 消息的 `styleMetrics` 字段里记录，供自进化闭环与成长面板使用。

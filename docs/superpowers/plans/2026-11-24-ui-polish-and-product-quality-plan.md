# 体验打磨与产品化计划：动效 · 布局 · 视觉 · 报错修复

> 日期：2026-11-24 · 级别：**L**（跨全部页面与组件，分 6 个 PR 交付）
> 依据：本地 `npm run dev` 实机走查（桌面 / 手机尺寸 / 深色模式 / 各页面）+ 代码扫描

---

## 0. 目标

把 PersonaBot 从「功能齐全的开发版」打磨成「像成熟 App 一样顺手」：
- **不出错**：任何失败都有清楚的提示和下一步，不再只写在控制台里
- **一致**：所有页面同一套颜色、圆角、按钮、间距、动效
- **有生命感**：动效服务于「像在和真人聊天」，轻、快、不打扰
- **哪里都能用**：从大屏到手机都排得开

### 1.2 视觉一致性（P1）

- **两套视觉并存**：工作台是 Apple 浅色极简风；登录 / 注册 / 管理后台 / 旧角色详情页还是「微信绿」风格（`#07C160` 出现 93 次），广场和蒸馏页又是第三种绿色卡片风
- **硬编码颜色多**：组件里直接写死的十六进制颜色数百处（`#07C160`、`#18a999`、`#1683FF`、`#999999`…），深色模式与后续改版都要逐个改
- **文案风格不统一**：标题中英混排加括号（如「角色引力场广场 (Persona Gravity Gallery)」「本地网关、生图表情包与模型设置舱」），emoji 过多
- **遗留组件**：`components/chat/*`、`components/ui/WeChat*`、`ChatWindow`、`SkillPanel`、`IntakeWizard` 只被旧页面使用，和现行设计冲突

### 1.3 动效现状

- 已有 23 组关键帧（吉祥物呼吸 / 眨眼 / 消息弹入 / 弹窗弹出 / 打字点…），基础不错
- 缺少统一的**时长与缓动规范**，各处时长不一
- 缺少几个关键时刻的过渡：切换角色、面板展开、列表重排、图片加载完成、好感度变化
- `prefers-reduced-motion` 只覆盖了部分动画

## 2. 设计原则

1. **聊天是主角**：动效只用在「消息来了 / 状态变了 / 位置变了」这三类时刻，其余保持安静
2. **快**：小元素 120~200ms，面板 / 弹窗 240~320ms，任何动效不超过 400ms；只动 `transform` 和 `opacity`
3. **有来处**：弹窗从触发点展开，面板从所在边滑入，列表重排有位移过渡
4. **可关闭**：系统开启「减少动态效果」时，全部降级为淡入淡出或直接切换
5. **一个 token 改全站**：颜色、圆角、阴影、间距、字号、动效全部走设计变量

## 3. 分阶段计划

### Phase 0：修报错与可用性 · M
- **E1 响应式骨架**（详见 Phase 3，先做可用的最小版本）：小于 768px 时侧栏变成抽屉、右侧面板变成底部弹层，聊天区占满
- **E2 统一提示系统**：新增轻量 `Toast` + `useToast()`（成功 / 警告 / 错误 / 可带「重试」按钮）；把 19 处静默失败都接上提示；加载失败的区域显示「重新加载」占位
- **E3 网关诊断**：设置页把 `fetch failed` 翻译成「本地网关 127.0.0.1:18630 没有响应 → 检查网关是否启动 / 端口 / 一键重试」；聊天顶部在离线演示时显示可点击的小标签「离线演示 · 去设置」
- **E4 预览清洗**：统一的 `toPlainPreview()` 去掉 Markdown、`[BURST]`/`[PHOTO]` 等标记和「[来自主控 Bot…]」前缀
- **E5 自研确认弹窗**：`ConfirmDialog` 替换 `confirm()`，复制成功改用 Toast
- **E6/E7**：开发角标挪到右下或关闭；清掉 lint 警告

**验收**：断网 / 关闭网关 / 接口 500 三种情况下都有可见提示和重试；375px 宽度能正常聊天；lint 0 警告。

### Phase 1：设计系统统一 · M
- **设计变量**：在 `globals.css` 补全并整理
  - 颜色：背景 4 级、文字 4 级、边框 2 级、品牌主色 1 个 + 语义色（成功 / 警告 / 危险 / 信息），深浅两套
  - 圆角：`sm 8 / md 12 / lg 18 / xl 24 / full`
  - 阴影：`flat / raised / overlay` 三级
  - 字号：`11 / 12 / 13 / 14 / 16 / 20 / 28` 七级，行高配套
  - 动效：时长 `fast 140 / base 200 / slow 300`，缓动 `standard / emphasized / spring`
- **基础组件**：`Button`（主 / 次 / 幽灵 / 危险 × 尺寸）、`IconButton`、`Chip`、`Card`、`Modal`、`Sheet`、`Tooltip`、`Toast`、`ConfirmDialog`、`Skeleton`
- **替换硬编码颜色**为变量（先工作台，再其他页面）
- **页面统一**：广场、蒸馏工作室、设置、登录 / 注册、管理后台、旧角色详情页迁移到工作台视觉；文案去括号英文、减 emoji
- **遗留清理**：确认无引用后删除旧组件；旧 `/persona/[slug]` 详情页并入右侧面板或重定向

**验收**：组件里不再出现 `#07C160` 等品牌色硬编码；所有页面深浅色都正确；截图对比风格一致。

### Phase 2：动效体系 · M
| 时刻 | 现在 | 打磨后 |
|------|------|--------|
| 角色回复 | 气泡整体弹入 | 打字指示器原地「长」成第一条气泡；多条气泡按 60ms 依次弹入 |
| 发送消息 | 直接出现 | 输入框内容轻微上移并淡入成用户气泡（乐观显示） |
| 切换角色 | 内容直接替换 | 聊天区淡出淡入 + 顶部角色名平滑切换；侧栏选中高亮条滑动到新位置 |
| 侧栏排序变化 | 跳动 | 有新消息的角色平滑移到顶部 |
| 右侧面板 | 出现 / 消失 | 从右侧滑入，内容延后 60ms 淡入；标签页切换时下划线滑动 |
| 弹窗 / 菜单 | 统一弹出 | 从触发按钮位置展开，关闭时反向收起 |
| 图片 / 表情包 | 加载完突然出现 | 模糊缩略图 → 清晰（blur-up），生成中保留现有闪光效果 |
| 好感度变化 | 数字变化 | 心形旁浮出「+1 / -2」小标签后消失；情绪雷达数值平滑过渡 |
| 成长日志 | 列表刷新 | 规则从「试用中」转到「生效中」时有位移动画和轻微高亮 |
| 滚动到底按钮 | 已有 | 新消息到达时显示未读数并轻跳一次 |

- 优先用 CSS（关键帧 + `transition`）实现，**不引入大型动画库**；列表重排用 FLIP 小工具函数实现
- 全量覆盖 `prefers-reduced-motion`

**验收**：所有动效走统一时长 / 缓动变量；减少动态效果开启后无位移动画；滚动与输入时无掉帧（Chrome Performance 面板检查）。

### Phase 3：布局与响应式 · M
| 宽度 | 布局 |
|------|------|
| ≥ 1280px | 三栏：侧栏 268 + 聊天（内容最大 720 居中）+ 右侧面板 320 |
| 1024~1279px | 侧栏 + 聊天；右侧面板变为覆盖式抽屉 |
| 768~1023px | 侧栏收成 72px 图标栏（悬停展开）；右侧面板抽屉 |
| < 768px | 单栏；侧栏为左滑抽屉，右侧面板为底部弹层；输入框适配安全区与软键盘；气泡最大宽度 85% |

- 聊天内容区统一最大宽度与行长，长段落、代码块、页面卡片、图片在各宽度下都不溢出
- 顶部栏在窄屏下精简（只保留角色名 + 菜单）

**验收**：375 / 768 / 1024 / 1440 四个宽度截图逐一检查；手机尺寸下完成「切换角色 → 发消息 → 看面板」全流程。

### Phase 4：细节体验 · M
- **加载状态**：切换角色、加载历史时显示骨架屏，而不是空白
- **空状态**：新角色第一次聊天给 3 个开场建议；没有记忆 / 没有成长记录时给出说明和入口
- **失败消息**：发送失败的气泡显示「重试」，不丢输入内容
- **键盘与无障碍**：快捷键速查（`?` 打开）；所有图标按钮有可读标签；焦点框清晰可见；深色模式对比度达标（WCAG AA）
- **微交互**：按钮按下有轻微缩放；长按 / 右键菜单有统一样式；复制、保存给出即时反馈
- **文案**：统一口吻（简洁、口语、不堆技术名词），错误信息都说明「发生了什么 + 怎么办」

### Phase 5：质量保障 · S
- 每个 PR 附桌面 / 手机 / 深色三张截图
- 走查清单：断网、网关关闭、接口报错、长文本、超长角色名、无头像、大量角色（20+）、大量消息（200）
- 用浏览器自带工具检查无障碍与性能（不新增依赖）

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| 与人格优化堆叠 PR（#8~#14）改的是同一批文件（`ChatStage`、`RightInspector`） | 叠在 #14 之上继续开发，或等那批合并后从 master 切出 |
| 大范围改样式引入视觉回归 | 每个 PR 附多尺寸截图；先换变量、后改结构 |
| 动效影响性能 | 只动 `transform` / `opacity`；列表超过 50 项时关闭重排动画 |
| 删除旧页面影响仍在用的入口 | 删除前全局搜索引用；旧路由先重定向一个版本 |
